# MKT-110 — Loop de referral organico

## Objetivo

Definir y activar una mecánica básica de recomendación orgánica para amplificar adquisición.

## Alcance (in-scope)

- Copy y plantillas de invitación compartible.
- Enlaces trazables para medir alta conversión por recomendación.
- Integración operativa con la cadencia de revisión.

## Criterios de aceptación

- [ ] **CA-1**: Existen plantillas de referral listas para uso en canales definidos.
- [ ] **CA-2**: El tráfico y conversión de referral se distinguen del resto de tráfico orgánico.
- [ ] **CA-3**: El resultado se incorpora al resumen operativo periódico.
